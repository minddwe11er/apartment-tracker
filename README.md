# Квартиры — трекер

Спільний трекер квартир: статичний фронтенд + Netlify Function (`/api/*`) + Netlify Blobs як сховище.

- Перегляд відкритий для всіх, хто має посилання.
- Редагування — за паролем зі змінної середовища **`APP_PASSWORD`** (Site configuration → Environment variables). Якщо змінну не задано, редагувати може будь-хто.
- Під час першого запиту сховище заповнюється даними з `netlify/functions/seed.json` (10 квартир, перенесених із Claude-артефакту); фото цих квартир лежать у `public/photos/`, нові фото — у Blobs.
- Оновлення між двома пристроями — опитуванням кожні 15 с і при поверненні на вкладку.
